# Semi-analytical solution to the frequency-dependent phonon Boltzmann transport equation for thermal transport in a two-layered system with interface: MATLAB codes
This repository contains the MATLAB code and data used to reproduce the figures presented in the associated research paper.

Requirements: MATLAB

Contents:
Fig04_code.m – Main MATLAB program.
Figures data – To reproduce figures.

How to Use:
Step 1: Download the Repository
Download or clone this repository to your computer.

Step 2: Open MATLAB
Open MATLAB and set the BTE_MATLAB repository folder as the current working directory.

Step 3: Run the MATLAB Code
Open Fig04_code.m in MATLAB and run the program. The code reads the required input data and generates the numerical results and corresponding figures.

Step 5: Compare the Results
The generated figures can be compared with the associated research paper.

Reproducibility:
The MATLAB code and input data provided in this repository are intended to enable reproduction of the figures reported in the associated research paper.
